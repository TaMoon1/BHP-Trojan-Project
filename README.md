# 🛠️ BHP-Trojan-Project：基于 GitHub C2 的无文件落地木马研究项目

本工具是一个基于经典网络安全著作《Python黑帽子：黑客与渗透测试编程之道（第2版）》第七章核心理论实现的**远程模块化动态加载控制通道（C2）研究项目**。

本项目创新性地利用 GitHub 官方 API 作为命令与控制（Command & Control）通道，通过自定义 Python 的 `sys.meta_path` 包导入机制，实现了远程恶意功能模块在目标机器“内存中直接动态加载与执行”的无文件落地特性。

## 🎯 核心技术特性

- **隐蔽控制通道 (Covert Channel)**：传统木马直接外连可疑 IP 极易被防火墙或 IDS（入侵检测系统）拦截。本项目完全基于标准的 HTTPS 协议与 `github.com` 通信，将所有的控制指令、心跳检测、数据外传流量完美隐匿于日常频繁的正常开发业务流量中。
- **无文件落地执行 (Fileless Execution)**：通过自定义 `GitImporter` 类拦截 Python 底层的 `import` 导入行为。当主程序接收到任务时，直接从远程 GitHub 仓库拉取加密的模块源码并注入到目标机内存空间执行。目标主机的磁盘从头到尾不留任何脚本痕迹，从而完美绕过传统的静态文件特征码杀毒软件。
- **动态模块化扩展**：控制端无需重新编译或替换主程序，仅需在云端修改 `config/abc.json` 任务清单或在 `modules/` 目录下上传新的 Python 渗透脚本，即可动态改变所有存活受害主机的执行行为，具备极强的隐蔽性与战术灵活性。

## 📂 项目目录结构说明

Plaintext

```
BHP-Trojan-Project/
├── .gitignore              # Git 忽略配置文件（已配置 my_token.txt 安全防护）
├── README.md               # 项目说明文档（本文件）
├── Trojan.py               # 木马核心控制引擎（运行于受害机）
├── my_token.txt            # [本地特有] GitHub 个人访问令牌凭证（已被 Git 强制忽略）
├── config/                 # 远程任务控制目录（存放于 GitHub 云端）
│   └── abc.json            # 任务控制清单（指定木马需要加载并执行的模块）
└── modules/                # 远程功能模块目录（存放于 GitHub 云端）
    ├── dirlister.py        # 目录结构侦察模块（搜集受害机当前文件列表）
    └── environment.py      # 系统环境变量收集模块（窃取系统敏感环境变量）
```

## ⚙️ 环境搭建与配置指南

### 1. 安装第三方依赖库

本工具依赖 `github3.py` 库与 GitHub 官方 API 进行安全、高匿的交互。在控制台运行以下命令：

Bash

```
pip install github3.py
```

### 2. 身份凭证配置

为了避免将敏感权限凭证误上传至公网引发安全风险，本项目采用“**外部凭证隔离存储**”机制。在项目根目录下新建 `my_token.txt`，并将你具备 `repo` 读写权限的 GitHub 经典令牌（Classic Token）粘贴进去：

Plaintext

```
ghp_YourPersonalAccessTokenHere...
```

### 3. 本地安全防护确认

请确保根目录下的 `.gitignore` 文件末尾已包含以下规则，Git 会自动过滤这些敏感路径：

Plaintext

```
my_token.txt
data/
```

## 🚀 实验验证与运行流程

1. **发布远程任务**：在云端 GitHub 仓库的 `config/abc.json` 中声明你希望受害机执行的功能模块：

   JSON

   ```
   [{"module": "environment"}, {"module": "dirlister"}]
   ```

2. **启动主控制引擎**：在目标机环境执行主程序：

   Bash

   ```
   python Trojan.py
   ```

3. **数据加密回传验证**：木马程序启动后会建立隐蔽通道，远程拉取代码并加载。执行完毕后，会自动在你的 GitHub 远程仓库中创建 `data/` 目录，并以 `victim_[随机ID]` 为命名，实时回传经过 **Base64 混淆加密**后的机密系统环境与目录结构数据。
